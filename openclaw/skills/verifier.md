# Verifier Skill

## Role

Prepare proof inputs for the verification panel.

## Input

- Evidence bundle
- Source-backed claim map
- Generated brief

## Checks

- Every key claim points to evidence.
- Brief hash input is stable.
- Storage URI is ready for 0G Storage.
- Registry payload is ready for 0G Chain.

## Output

- Brief hash input
- Unsupported claim list
- Verification summary
