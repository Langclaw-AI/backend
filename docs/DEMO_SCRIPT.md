# SignalGraph Demo Script

Use this script for the 3 minute HackQuest video.

## 0:00 to 0:20

Say:

```text
Teams waste hours reading noisy public signals before they decide what to build. SignalGraph turns one topic into live X, GitHub, Docs, and HackQuest signals for a verified trend brief.
```

Show:

- SignalGraph AI chat
- Track 1 badge
- Product one-liner

## 0:20 to 0:50

Say:

```text
I enter one topic. SignalGraph uses OpenClaw as the reasoning layer. Planner, Trend Scorer, Evidence Packager, Verifier, and Final Conclusion run through OpenClaw agent sessions.
```

Show:

- Chat history sidebar
- New Chat button
- SignalGraph AI chat composer
- Suggested topic prompts
- Send button

## 0:50 to 1:30

Say:

```text
The web app only sends a topic. TypeScript provider tools collect live sources, OpenClaw agents plan and verify the reasoning, and 0G Compute can write the final answer through an OpenAI-compatible Router call.
```

Show:

- Agent Process panel
- Thinking animation
- Natural AI chat answer
- Collapsible Sources and Agent Trace
- Answer: OpenClaw AI badge
- Answer: 0G Compute badge when Router envs are active
- Execution badges: OpenClaw agent, TypeScript tool, or Fallback
- 0G Storage and 0G Chain execution badges
- Complete badges
- OpenClaw Agent Outputs
- Sources Used
- Source-backed findings

## 1:30 to 2:10

Say:

```text
The output reads like a normal AI answer. The Final Conclusion Agent uses 0G Compute when the Router API key is configured, then falls back to OpenClaw if needed. The details show ranked trends, claim maps, verifier notes, and session ids behind the OpenClaw steps.
```

Show:

- Final chat answer
- Recommendation
- Sources and Agent Trace details
- Ranked trend scores
- Evidence claim map
- Verifier summary

```text
The Web3 layer is now transaction-ready. SignalGraph builds a canonical evidence bundle, uploads it to 0G Storage when wallet envs are enabled, then anchors the final brief hash and storage URI through the SignalGraphRegistry contract on 0G Chain.
```
